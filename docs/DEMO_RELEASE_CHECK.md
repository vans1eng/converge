# Converge Demo 0.1.0 验证记录

检查日期：2026-10-04。检查环境：macOS / Apple M3 Pro，Godot 4.7 stable（5b4e0cb0f）。

结论：可以作为小范围试玩测试包。已经成功生成 Windows x64 和 macOS universal Release 包；公开发布仍需完成下文的签名、素材信息及目标设备验证。

## 本轮修复

- 补齐韩文字体子集中的关卡教学字符。原工具只读取翻译 CSV，漏掉了关卡 JSON 中的韩文教学；现在两处都会纳入字库。
- 主菜单和游戏中的反引号编辑器快捷键仅在编辑器运行时开放，导出版本关闭。
- 导出排除关卡编辑器、测试场景以及第二章 JSON，试玩包实际只包含第一章 30 关。开发项目保留第二章。
- 项目版本、关于页和导出版本统一为 0.1.0；Windows 文件版本为 0.1.0.0。
- 新玩家默认窗口改为 1280×720。原默认 1920×1080 在小屏幕上可能显示不全；已有玩家的有效分辨率设置仍保留。
- 冷启动字库测试改为等待真实绘制完成，不再要求不同设备都在固定 0.3 秒内完成预热。

| 检查 | 结果 |
| --- | --- |
| Windows x64 Release 导出 | 成功，EXE 与同名 PCK 均生成 |

| macOS 原生启动 | 独立程序可启动，主菜单正常显示；未在 Intel Mac 上验证 |

| 第一章关卡 | 30 关加载、281 个可填写答案校验和通关状态检查通过 |
| 解锁与存档 | 首关解锁、逐关通关保存、重新读取、末关边界通过；测试使用独立存档 |
| 正式包资源边界 | 编辑器、测试场景、第二章数据不包含在试玩 PCK 中 |

关卡测试验证现有答案和通关逻辑，不等于穷举所有解或人工完成全部谜题。PCK 自动检查使用编辑器运行器加载正式资源包，不等同于 Windows EXE 在目标系统上的测试。macOS 原生验证确认了启动与主菜单显示；原生按钮操作的自动化没有获得可靠的导航结果，仍需人工复核。

## 对外发布前仍需处理

1. **macOS 签名与公证。** 当前使用 ad-hoc 签名，没有 Developer ID / 公证。`codesign --verify --deep --strict` 校验通过，但 `spctl --assess --type execute` 返回 `rejected`；不能将此包视为已通过 Gatekeeper 的公开分发版本。
2. **Windows 真机验证。** 本机没有 Windows / Wine 运行环境，尚未验证 Windows EXE 的实际启动、显卡兼容、声音、全屏、鼠标操作及首次存档。建议至少在一台 Windows 电脑上完成首关、重启确认解锁、切换设置与退出。
3. **素材信息。** 音乐与音效的作者、来源或制作说明仍显示“待补充”；仓库中未见 MiSans 的许可文本。发布前确认实际来源，并补齐适用的许可和致谢信息。当前关于页的许可入口包含 Noto Sans KR 和 Godot 的文本。
4. **小屏幕与旧设置。** 默认窗口已改善，但用户主动选择较高分辨率或已有较高分辨率存档时，当前逻辑仍未按可用屏幕范围自动限制窗口尺寸。可在低分辨率设备上进一步确认。

部分源项目测试退出时仍出现音频资源清理警告（ObjectDB / 音频流资源）；测试断言均通过，正式资源包自动流程运行日志未出现脚本错误。该现象尚未被证明会影响正常游玩。
